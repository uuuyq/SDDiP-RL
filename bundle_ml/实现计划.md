
# Bundle ML 模块实现计划

## 概述

本计划描述如何实现一个基于 Attention 的 Neural Warm Start 模块，用于加速 Lagrangian 子问题的求解。

## 参考架构

根据 `架构设计.md`，模型采用以下结构：

```
                Bundle Cuts
                     ↓
               Cut Encoder
                     ↓
            Self-Attention
                     ↓
            Attention Pooling
                     ↓
             Bundle Embedding

------------------------------------------------

(λ, realization, x_prev, stage)
                     ↓
              Global Encoder
                     ↓
             Global Embedding

------------------------------------------------

(Bundle Embedding + Global Embedding)
                     ↓
              Shared Feature
                     ↓
         ┌────────────────┐
         ↓                ↓
      x_t Head         z_t Head
         ↓                ↓
      x_init           z_init
```

## 已确认的问题

### 问题 1: 输入输出维度

| 特征 | 描述 | 维度 | 如何获取 |
|------|------|------|----------|
| λ | 当前对偶变量 | 13 | 来自 `SubProblem.solve(pi)` 的输入 |
| x_prev | 上一阶段状态 | 13 | 来自 config.trial_point (x, y, x_bs, soc 展开) |
| realization | 场景特征 | 2 | demand, renewable generation |
| stage | 阶段索引 | - | stage embedding |

### 问题 2: Cut 特征细节

| 特征 | 描述 | 维度 | 如何获取 |
|------|------|------|----------|
| g_i | cut 子梯度 | 13 | 来自 `MasterProblem.get_all_cuts()` |
| phi_i | cut 截距 | 1 | 计算: phi_i = f_new - g_i @ x_new |
| age_i | cut 生成时间 | - | **暂不实现，留空** |
| violation_i | 当前 violation | - | **暂不实现，留空** |
| activity_i | 近期是否 active | - | **暂不实现，留空** |

### 问题 3: 输出目标

- **目标**: 模型直接预测 subgradient 和 opt_value，完全替代 Gurobi 求解
- **x_init 和 z_init**: 对应 (x, y, x_bs, soc) 和 (z_x, z_y, z_x_bs, z_soc)
- **集成模式**: 支持 "replace" (完全替代) 和 "warm_start" (提供初始值)，先实现 "replace"

### 问题 4: 数据收集策略

- 数据来源: 从 `sddipclassical_without_binary_with_bundle_RL.py` 外层执行收集
- 收集内容: 每次迭代的 (λ, realization, x_prev, stage, bundle_cuts, subgradient*, opt_value*)
- **数据收集模块暂不实现，后续补充**

### 问题 5: 模型集成方式

- 支持两种模式: "replace" (完全替代) 和 "warm_start" (提供初始值)
- 先实现 "replace" 模式
- 通过 `MLSubProblem` 类集成到现有框架

## 使用示例

### 1. 独立使用模型

```python
from bundle_ml import NeuralWarmStartModel, MLConfig

# 创建模型
config = MLConfig()
model = NeuralWarmStartModel(config=config)

# 准备数据
cuts = torch.randn(batch_size, num_cuts, cut_dim)
valid_mask = torch.ones(batch_size, num_cuts, dtype=torch.bool)
lambda_ = torch.randn(batch_size, lambda_dim)
x_prev = torch.randn(batch_size, x_prev_dim)
realization = torch.randn(batch_size, realization_dim)
stage = torch.randint(0, 10, (batch_size,))

# 推理
predictions = model(
    cuts=cuts,
    valid_mask=valid_mask,
    lambda_=lambda_,
    x_prev=x_prev,
    realization=realization,
    stage=stage,
)

# 获取输出
subgradient = predictions["subgradient"]
opt_value = predictions["opt_value"]
```

### 2. 集成到 lag_problem

```python
from bundle_ml import MLSubProblem
from bundle_RL.config import get_default_config
from bundle_ml.lag_problem import MasterProblem

# 配置
config = get_default_config()
logger = ...

# 创建 ML 求解器
ml_subproblem = MLSubProblem(
    logger=logger,
    config=config,
    n=0,
    mode="replace",  # 或 "warm_start"
    model_path="path/to/model.pth",
)

# 创建 Master
master = MasterProblem(logger, config.N_VARS, tolerance=1e-5)

# 求解
pi = np.zeros(config.N_VARS)
subgradient, opt_value = ml_subproblem.solve(pi, master=master)
```

### 3. 保存/加载模型

```python
# 保存
model.save("model.pth")

# 加载
loaded_model = NeuralWarmStartModel.load("model.pth")
```
