# Bundle ML 模型架构设计

## 1. 整体架构

```
输入:
├── cuts: (batch_size, num_cuts, cut_dim=14)  -- g_i (13) + phi_i (1)
├── valid_mask: (batch_size, num_cuts)        -- True 表示有效
├── lambda_: (batch_size, lambda_dim=13)      -- 对偶变量
├── x_prev: (batch_size, x_prev_dim=10)       -- 状态: x, y, x_bs, soc
├── realization: (batch_size, realization_dim=12) -- p_d(6) + re(6)
└── stage: (batch_size,)                      -- 阶段索引

输出:
├── subgradient: (batch_size, 13)
└── opt_value: (batch_size, 1)
```

## 3. 各模块详解

### 3.1 CutEncoder
```
输入: cuts (batch, num_cuts, 14)
输出: embeddings (batch, num_cuts, 64)

结构:
  Linear(14, 64) → ReLU → Linear(64, 64) → ReLU
```

**参数量**: `(14×64 + 64) + (64×64 + 64) = 896 + 4,160 = 5,056`

### 3.2 SelfAttention (每层)
```
输入: embeddings (batch, num_cuts+1, 64)
输出: attended (batch, num_cuts+1, 64)

结构:
  MultiHeadAttention(embed_dim=64, num_heads=4)
    ├── Q, K, V projection: 64 → 192
    └── output projection: 64 → 64

  FFN:
    Linear(64, 128) → ReLU → Linear(128, 64)

  LayerNorm × 2
```

**参数量**: `16,640 + 16,576 + 256 = 33,472` (单层)

### 3.3 AttentionPooling
```
输入: attended (batch, num_cuts+1, 64)
输出: bundle_embedding (batch, 64)

结构:
  Attention: Linear(64, 32) → ReLU → Linear(32, 1)
  Softmax → weighted sum
```

**参数量**: `(64×32 + 32) + (32×1 + 1) = 2,080 + 33 = 2,113`

### 3.4 GlobalEncoder
```
输入:
  - lambda_: (batch, 13)
  - x_prev: (batch, 10)
  - realization: (batch, 12)
  - stage: (batch,) [可选]

输出: global_embedding (batch, 64)

结构:
  concat(lambda_, x_prev, realization) → (batch, 35)
  Linear(35, 64) → ReLU → Linear(64, 64) → ReLU → (batch, 64)

  stage_embedding: Embedding(100, 64)
  fusion: concat(encoder_out, stage_emb) → Linear(128, 64) → ReLU → Linear(64, 64) → ReLU
```

**参数量**: `(35×64 + 64) + (64×64 + 64) + 100×64 + (128×64 + 64) + (64×64 + 64) = 2,304 + 4,160 + 6,400 + 8,256 + 4,160 = 25,280`

### 3.5 PredictionHead
```
输入: shared_features (batch, 128) = concat(bundle_emb, global_emb)
输出:
  - subgradient: (batch, 13)
  - opt_value: (batch, 1)

结构:
  Shared: Linear(128, 128) → ReLU → Linear(128, 128) → ReLU

  Subgradient Head: Linear(128, 13)
  Opt Value Head: Linear(128, 1)
```

**参数量**: `(128×128 + 128) × 2 + 128×13 + 13 + 128×1 + 1 = 33,024 + 1,677 + 129 = 34,830`

## 4. 参数汇总

| 模块 | 参数量 | 占比 |
|------|--------|------|
| CutEncoder | 5,056 | 6.2% |
| SelfAttention × 1 | 33,472 | 41.2% |
| AttentionPooling | 2,113 | 2.6% |
| GlobalEncoder | 25,280 | 31.1% |
| PredictionHead | 34,830 | 42.9% |
| **总计** | **~81,243** | 100% |

## 5. 维度信息

### 输入维度
| 特征 | 维度 | 说明 |
|------|------|------|
| lambda_ | 13 | 对偶变量 (α, β, γ, ...) |
| x_prev | 10 | 状态变量 (X:3, Y:3, X_BS:6展开, SOC:1) |
| realization | 12 | 场景实现 (Pd:6, Re:6) |
| cut | 14 | Cut 特征 (g_i:13, φ_i:1) |

### 中间维度
| 模块 | 输入维 | 输出维 |
|------|--------|--------|
| CutEncoder | 14 | 64 |
| SelfAttention | 64 | 64 |
| AttentionPooling | 64 | 64 |
| GlobalEncoder | 35 | 64 |
| PredictionHead | 128 | 13/1 |

## 7. 数据流总结

```
1. cuts + valid_mask
   └──► CutEncoder → SelfAttention → AttentionPooling → Bundle Embedding (64)

2. lambda_ + x_prev + realization + stage
   └──► GlobalEncoder → Global Embedding (64)

3. Bundle Embedding + Global Embedding
   └──► Concat (128) → PredictionHead → Subgradient (13) + OptValue (1)
```
