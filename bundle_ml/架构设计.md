# Attention-based Neural Warm Start for Bundle-based Parametric Optimization

## 1. 当前目标与问题形式

当前考虑如下多阶段随机优化中的参数化子问题：

$$
\phi(\lambda)=
\min_{x_t,z_t}
\;
c_t(x_t,\xi_t)
+
\theta_{t+1}(x_t)
+
\lambda^\top(x_{t-1}-z_t)
$$

subject to

$$
T_t z_t + W_t x_t \ge h_t(\xi_t)
$$

$$
x_t \in X_t
$$

其中：

- $\lambda$ 为当前 dual variable；
- $x_{t-1}$ 为上一阶段状态；
- $\xi_t$ 为当前 realization/scenario；
- $\theta_{t+1}$ 为未来价值函数近似；
- $x_t,z_t$ 为当前阶段优化变量。

与普通参数化优化不同，当前问题中的：

$$
\theta_{t+1}(x)
$$

并不是固定函数，而是由多个 bundle cuts 构成的近似函数：

$$
\theta_{t+1}(x)
=
\max_i
\{
g_i^\top x + \phi_i
\}
$$

因此，当前优化问题不仅依赖于：

- 当前的 $\lambda$
- realization $\xi_t$
- previous state $x_{t-1}$

还强依赖于：

# 当前 bundle 中的全部 cuts

即：

```text
cut_1,
cut_2,
...
cut_n
```

其中：

- cut 数量动态变化；
- cut 顺序本身无意义；
- 不同 cut 之间存在相关性与冗余性；
- 不同 cut 对当前优化状态的重要程度不同。

因此，本问题本质上是：

# 基于动态 cut-set 的参数化优化问题。

当前目标并不是直接使用神经网络替代优化器，而是学习：

# Neural Warm Start

即：

```text
(problem state, bundle cuts, λ)
                    ↓
              Neural Network
                    ↓
          predicted (x_init,z_init)
                    ↓
             Gurobi Refinement
                    ↓
               Exact Solution
```

通过预测接近最优的 primal initialization，加速后续优化求解过程。

---

## 2. 监督学习模型架构

由于 bundle cuts 本质上属于：

# variable-length unordered set

因此普通 MLP 无法有效建模。若直接对 cuts 进行 flatten：

```text
flatten(cut_1,...,cut_n)
```

则会导致：

- 无法支持动态 cut 数量；
- 对 cut 顺序敏感；
- 泛化能力较差；
- 难以学习 cut interaction。

因此，当前模型采用：

# Attention-based Set Encoder

对 bundle cuts 进行编码。

整体模型结构如下：

```text
                Bundle Cuts
                     ↓
               Cut Encoder
                     ↓
            Self-Attention
                     ↓
            Attention Pooling
                     ↓
             Bundle Embedding

------------------------------------------------

(λ, realization, x_prev, stage)
                     ↓
              Global Encoder
                     ↓
             Global Embedding

------------------------------------------------

(Bundle Embedding + Global Embedding)
                     ↓
               Shared Feature
                     ↓
           ┌────────────────┐
           ↓                ↓
        x_t Head         z_t Head
           ↓                ↓
        x_init           z_init
```

模型输入由两部分组成。

第一部分为：

# Global Features

包括：

```text
λ
x_prev
realization features
stage embedding
```

其中：

- $\lambda$ 表示当前 dual variable；
- $x_{t-1}$ 表示上一阶段状态；
- realization features 包括 demand、renewable generation、scenario probability 等随机场景特征；
- stage embedding 用于区分不同阶段的 optimization distribution。

第二部分为：

# Bundle Cut Features

每个 cut 表示为：

```text
cut_i = {
    g_i,
    phi_i,
    age_i,
    violation_i,
    activity_i
}
```

其中：

- $g_i$ 为 cut subgradient；
- $\phi_i$ 为 cut intercept；
- $age_i$ 表示 cut 生成时间；
- $violation_i$ 表示当前 violation；
- $activity_i$ 表示近期是否 active。

首先，每个 cut 经由共享 MLP Encoder：

```python
Linear(cut_dim, 64)
ReLU
Linear(64, 64)
```

映射为：

$$
h_i \in \mathbb{R}^{64}
$$

随后，对所有 cut embedding：

$$
H=[h_1,h_2,\dots,h_n]
$$

使用 Self-Attention 进行建模：

```python
MultiHeadAttention(
    d_model=64,
    num_heads=4
)
```

Attention 的作用在于学习：

- cut importance；
- cut redundancy；
- cut interaction；
- active cuts。

由于 cuts 本质上是 set 而不是 sequence，因此：

# 不使用 Position Encoding

以保证 permutation invariance。

Attention 输出后，使用 Attention Pooling：

$$
\alpha_i
=
\text{softmax}(W h_i)
$$

$$
h_{bundle}
=
\sum_i \alpha_i h_i
$$

得到：

$$
h_{bundle}\in\mathbb{R}^{64}
$$

与此同时，global features 经由：

```python
Linear(global_dim, 64)
ReLU
Linear(64, 64)
```

得到：

$$
h_{global}\in\mathbb{R}^{64}
$$

随后：

$$
h=
[h_{bundle},h_{global}]
$$

形成 shared representation。

最后，通过两个 prediction heads：

```python
Linear(128, 128)
ReLU
Linear(128, output_dim)
```

分别预测：

```text
x_init
z_init
```

当前推荐的默认网络规模如下：

```text
Cut Encoder Hidden Dim : 64
Attention d_model      : 64
Attention Heads        : 4
Attention Layers       : 1
FFN Dim                : 128
Global Encoder Dim     : 64
Prediction Head Dim    : 128
```

当前问题的数据规模与 optimization noise 较大，因此：

# 小规模 Attention 模型通常比深层 Transformer 更稳定。

## 3. Loss 设置

当前模型采用监督学习训练。

对于优化器生成的最优解：

$$
x^*,z^*
$$

模型输出：

$$
x_{pred},z_{pred}
$$

基础回归 loss 定义为：

$$
L_x
=
\|x_{pred}-x^*\|_2^2
$$

$$
L_z
=
\|z_{pred}-z^*\|_2^2
$$

由于 optimization 问题具有可行域约束，因此仅依赖 regression loss 不足以保证预测解具有良好的 feasibility。

因此，引入 feasibility penalty：

$$
L_{feas}
=
\max(
0,
h_t(\xi_t)-T_t z-W_t x
)
$$

用于约束模型学习：

# 接近可行域的 initialization。

最终 loss 定义为：

$$
L
=
\alpha L_x
+
\beta L_z
+
\gamma L_{feas}
$$

其中：

- $\alpha,\beta$ 控制 solution regression；
- $\gamma$ 控制 feasibility importance。

训练过程中，所有输入特征：

```text
λ
x_prev
realization features
cut features
```

均进行 mean/std normalization，以提高训练稳定性。

## 4. 数据收集与训练数据构建

当前问题属于：

# 多阶段 + 多场景 + 多迭代

的随机优化问题。

因此，仅收集最终收敛解并不足够。

模型需要学习：

- 不同 optimization stage；
- 不同 realization；
- 不同 bundle quality；
- 不同 dual region；
- 不同 optimization iteration；

下的 optimization behavior。

因此，训练数据应来自：

# 完整 optimization trajectories

而不仅仅是最终状态。

每个训练样本定义为：

```text
Sample = {

    stage_id,

    realization,

    λ,

    x_prev,

    bundle_cuts,

    optimal x*,

    optimal z*,

    objective value,

    metadata
}
```

其中：

- bundle_cuts 为当前 iteration 的全部 cuts；
- optimal solution 由真实优化器生成；
- 不同 iteration 会对应不同 bundle approximation quality。

数据采集过程中，需要覆盖：

```text
不同 stage
不同 scenario
不同 λ
不同 optimization iteration
不同 bundle size
```

尤其需要注意：

# 不同 dual region 的覆盖

否则模型会在 unseen λ 上泛化较差。

推荐的数据来源为：

```text
多个完整 SDDP / Bundle runs
```

并保存：

```text
iteration 1
iteration 2
...
iteration N
```

的完整 optimization trajectories。

第一阶段推荐数据规模：

```text
100k ~ 1M samples
```

用于训练统一的 conditional warm-start model。

最终在线推理阶段：

```text
(current optimization state)
            ↓
Attention-based Neural Warm Start
            ↓
predicted x_init,z_init
            ↓
Gurobi refinement
            ↓
exact solution
```

实现：

# 不同阶段 + 不同场景 + 不同 bundle 状态

上的统一泛化求解加速。
