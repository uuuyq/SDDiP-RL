# Attention-Based Bundle Method RL 模块架构设计

---

## 一、模块概述

本模块实现了基于注意力机制的 Bundle Method 强化学习框架，用于求解随机双线性规划问题（SDDiP）的对偶优化。核心思想是利用 Transformer 架构对 Bundle 中的多个 cutting plane 进行建模，学习最优的权重组合策略。

### 1.1 核心目标

- 学习如何智能地组合历史 cutting plane，生成高质量的对偶点更新方向
- 替代传统的启发式 Bundle Method（如 Level Method、Bundle Trust Region）
- 通过强化学习自动优化步长和权重分配策略

### 1.2 技术栈

| 组件 | 技术/框架 | 版本要求 |
|------|----------|----------|
| 深度框架 | PyTorch | >= 2.0 |
| RL 框架 | Stable-Baselines3 | >= 2.0 |
| 环境接口 | Gymnasium | >= 0.29 |

### 3.2 数据流分析

#### 3.2.1 输入数据

| 输入项 | Shape | 含义 | 来源 |
|--------|-------|------|------|
| `cuts` | (batch_size, K, state_dim) | K个cut的次梯度向量 | Bundle历史 |
| `valid_mask` | (batch_size, K) | 有效cut的掩码（1=有效） | Bundle管理 |
| `pi` | (batch_size, state_dim) | 当前对偶点 | 状态跟踪 |
| `trial_point` | (batch_size, trial_point_dim) | 试验点特征 | 问题配置 |
| `realization` | (batch_size, realization_dim) | 场景数据特征 | 问题实例 |

#### 3.2.2 输出数据

| 输出项 | Shape | 含义 | 用途 |
|--------|-------|------|------|
| `lambda_weights` | (batch_size, K) | 各cut的权重（归一化） | 方向合成 |
| `eta` | (batch_size, 1) | 步长（0~1） | 对偶点更新 |

#### 3.2.3 状态转移流程

```
action = [λ₁, λ₂, ..., λ_K, η]
       │
       ▼
┌─────────────────────────┐
│ 1. λ 归一化 (Softmax)   │
│ 2. 使用mask过滤无效cut  │
│ 3. 合成方向 d = Σλ_i·g_i│
│ 4. 更新 π ← π + η·d     │
│ 5. 求解子问题得到新cut  │
│ 6. 计算 Log-Gap Reward  │
└─────────────────────────┘
```

## 四、核心组件详解

### 4.1 Encoder 模块

#### 4.1.1 CutEncoder

```python
class CutEncoder(nn.Module):
    # 输入: g_i (state_dim,)
    # 输出: h_i (hidden_dim,)
    # 结构: Linear → ReLU → Linear → ReLU
```

**设计意图**：将原始次梯度向量映射到高维特征空间，为后续注意力计算做准备。

#### 4.1.2 SelfAttention

```python
class SelfAttention(nn.Module):
    # 输入: (batch_size, seq_len, d_model)
    # 输出: (batch_size, seq_len, d_model)
    # 结构: Multi-Head Attention → LayerNorm → FFN → LayerNorm
```

**设计意图**：通过自注意力机制建模 cut 之间的依赖关系，学习哪些 cut 应该被重点关注。

**关键特性**：
- 支持 key_padding_mask 处理可变长度序列
- 残差连接 + LayerNorm 保证训练稳定性
- 可堆叠多层（num_layers 参数）

#### 4.1.3 GlobalEncoder

```python
class GlobalEncoder(nn.Module):
    # 输入: [pi, trial_point, realization] 拼接
    # 输出: global_embedding (hidden_dim,)
```

**设计意图**：编码全局上下文信息（当前对偶点、试验点、场景数据），使策略能够感知当前问题状态。

#### 4.1.4 AttentionBundleEncoder（完整编码器）

```python
class AttentionBundleEncoder(nn.Module):
    # 整合 CutEncoder + SelfAttention + GlobalEncoder
    # 输出: cut_embeddings, global_embedding, cls_embedding
```

**编码流程**：
1. CutEncoder 编码每个 cut
2. 添加 CLS Token
3. 多层 Self-Attention 处理序列
4. GlobalEncoder 编码全局信息
5. 分离 CLS 和 Cut 输出

#### 4.1.5 V1 vs V2 差异

| 版本 | 输出Mask | 特点 | 推荐场景 |
|------|---------|------|----------|
| V1 (`encoder.py`) | 无 | 简单直接 | 快速验证 |
| V2 (`encoder_v2.py`) | 有 | 消除padding噪声 | **生产环境** |

**V2 核心改进**：
```python
# V2 新增：输出前对无效位置进行 mask
cut_embeddings = cut_embeddings * valid_mask.unsqueeze(-1)
```

### 4.2 Environment 模块

#### 4.2.1 BundleDualEnv

**状态空间**：
```python
observation_space = Dict({
    "cuts": Box(..., shape=(K, state_dim)),      # K个cut
    "valid_mask": Box(..., shape=(K,)),          # 有效性掩码
    "pi": Box(..., shape=(state_dim,)),          # 当前对偶点
    "trial_point": Box(..., shape=(trial_point_dim,)),
    "realization": Box(..., shape=(realization_dim,))
})
```

**动作空间**：
```python
action_space = Box(low=-1, high=1, shape=(K+1,))
# 前K维: raw_lambda（softmax归一化）
# 最后1维: raw_eta（sigmoid映射到(0,1)）
```

**奖励函数（Log-Gap Reward）**：
```python
gap_old = max(0, -phi_old) + eps
gap_new = max(0, -phi_new) + eps
raw_reward = log(gap_old) - log(gap_new)
reward = tanh(raw_reward * 0.1)  # 压缩到(-1,1)
```

**设计原理**：
- 当 gap 减小时，reward 为正
- 当 gap 增大时，reward 为负
- 使用 tanh 压缩防止梯度爆炸

### 4.4 Policy Network 模块

#### 4.4.1 LambdaHead / EtaHead

```python
class LambdaHead(nn.Module):
    # 输出每个cut的权重
    # 输入: cut_embeddings (batch_size, K, hidden_dim)
    # 输出: lambda_weights (batch_size, K)

class EtaHead(nn.Module):
    # 输出步长
    # 输入: global_embedding (batch_size, hidden_dim)
    # 输出: eta (batch_size, 1), 范围(0,1)
```

#### 4.4.2 策略选择

| 策略类型 | Encoder共享 | 适用场景 | 参数效率 |
|----------|------------|----------|----------|
| `MultiInputActorCriticPolicy` | 是 | **默认推荐** | 高 |
| `SeparateEncoderPolicy` | 否 | 需独立优化 | 低 |

│  │ 2. 创建策略网络 MultiInputActorCriticPolicy             │  │

### 5.2 Clip Range 衰减策略

```python

```

**设计意图**：训练初期允许较大策略更新，后期逐渐精细调整。

## 六、关键设计决策

### 6.1 为什么使用 Attention？

1. **可变长度处理**：Bundle 中 cut 数量随迭代变化，Attention 天然支持
2. **关系建模**：学习 cut 之间的依赖关系，识别"有用"的 cut
3. **全局视角**：CLS Token 提供序列级表示，增强决策能力

### 6.2 为什么使用 PPO？

1. **稳定训练**：Clip 机制防止策略更新过大
2. **样本效率**：GAE + 多轮更新提升数据利用率
3. **成熟框架**：SB3 提供完整的训练基础设施

### 6.3 Lambda 归一化策略

```python
exp_lambda = np.exp(raw_lambda - np.max(raw_lambda))  # 防止数值溢出
lambdas = exp_lambda / (np.sum(exp_lambda) + 1e-8)

# 使用mask过滤无效cut
masked_lambdas = lambdas * valid_mask
normalized_lambdas = masked_lambdas / (np.sum(masked_lambdas) + 1e-8)
```

## 七、扩展方向

### 7.1 可改进点

| 方向 | 描述 | 优先级 |
|------|------|--------|
| 位置编码 | 为 cut 添加位置信息（时序特征） | 中 |
| 动态 K | 根据性能自适应调整最大 cut 数 | 低 |
| 分层架构 | 支持更复杂的层次化注意力 | 低 |
| 正则化 | 添加更多正则化机制（如 Weight Decay） | 低 |

### 7.2 未来工作

1. **Cut Selection 机制**：学习动态选择/丢弃 cut
2. **自适应步长**：更精细的步长学习策略
3. **多阶段训练**：先预训练再微调
4. **迁移学习**：跨问题实例迁移策略
