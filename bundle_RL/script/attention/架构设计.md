========================================================
        RL-based Attention Bundle Method
========================================================

目标：
学习 Bundle Method 中：
1. cut aggregation strategy
2. step size strategy

而不是直接学习 dual variable π


========================================================
1. Environment
========================================================

-------------------------
State (变长输入)
-------------------------

state = {
    
    cuts: [
        cut_1,
        cut_2,
        ...
        cut_n
    ],

    global_state: {
        current_pi,
        trial_point,
        realization
    }
}

其中：

cut_i = {
    g_i,            # subgradient
    phi_i,          # cut对应目标值
    pi_i,           # 生成该cut时的dual point
    age_i,          # cut年龄
    error_i         # linearization error（可选）
}


--------------------------------------------------------
State特点
--------------------------------------------------------

1. cuts是变长集合（set/sequence）
2. 不使用padding
3. 不使用mask
4. 每轮bundle大小可变化


========================================================
2. Policy Network (Actor)
========================================================

整体结构：

cuts
  ↓
Cut Encoder
  ↓
Self-Attention / Transformer
  ↓
融合global_state
  ↓
输出lambda分布
  ↓
聚合direction
  ↓
输出eta
  ↓
更新pi


========================================================
3. Cut Encoder
========================================================

每个cut独立编码：

h_i = CutEncoder(cut_i)

例如：

cut_feature_i =
[
    g_i,
    phi_i,
    pi_i,
    age_i,
    error_i
]

经过MLP：

h_i = MLP(cut_feature_i)

得到：

H = [h_1, h_2, ..., h_n]


========================================================
4. Self-Attention over Cuts
========================================================

TransformerEncoder(H)

作用：

1. 学习cuts之间关系
2. 判断哪些cuts冗余
3. 判断哪些cuts冲突
4. 学习bundle几何结构

输出：

H_tilde =
[
    h̃_1,
    h̃_2,
    ...
    h̃_n
]


========================================================
5. Global State Fusion
========================================================

global_state 包括：

global_state =
[
    current_pi,
    realization,
    trial_point
]

先编码：

g = GlobalEncoder(global_state)

--------------------------------------------------------
推荐方式：CLS Token
--------------------------------------------------------

将g作为CLS token加入attention：

sequence =
[
    g,
    h̃_1,
    h̃_2,
    ...
    h̃_n
]

再次经过attention：

Transformer(sequence)

这样：

1. global信息与cuts自动融合
2. current_pi会影响cut重要性
3. realization会影响aggregation策略


========================================================
6. Lambda Policy Head
========================================================

对每个cut输出score：

score_i = Linear(h̃_i)

得到：

scores =
[
    score_1,
    score_2,
    ...
    score_n
]

softmax：

lambda_i =
softmax(scores)

得到：

λ =
[
    λ_1,
    λ_2,
    ...
    λ_n
]

满足：

λ_i ≥ 0
Σ λ_i = 1


========================================================
7. Direction Aggregation
========================================================

使用attention权重聚合：

d =
Σ λ_i g_i

得到bundle方向。


========================================================
8. Step Size Head
========================================================

对global embedding输出eta：

eta =
sigmoid(MLP(h_global))

满足：

0 < eta < 1

最终更新：

pi_{t+1} =
pi_t + eta * d


========================================================
9. Critic Network
========================================================

Critic输入：

1. pooled bundle embedding
2. global embedding

输出：

V(s)

Critic结构：

ValueNetwork(
    pooled_bundle_embedding,
    global_embedding
)


========================================================
10. RL Training
========================================================

--------------------------------------------------------
训练算法
--------------------------------------------------------

推荐：

PPO


========================================================
11. PPO中的Action
========================================================

当前action不再是：

action = [lambda, eta]

而是：

--------------------------------------------------------
Policy内部生成lambda
--------------------------------------------------------

lambda由attention自动生成：

lambda_i =
softmax(score_i)

因此：

lambda不再作为外部连续动作。

--------------------------------------------------------
真正需要RL采样的只有：
--------------------------------------------------------

eta

例如：

eta ~ Beta distribution
或者：
eta ~ Gaussian + sigmoid


========================================================
12. 为什么仍然是RL
========================================================

虽然lambda来自attention：

但attention参数：

θ = {
    encoder,
    transformer,
    lambda_head
}

仍然通过：

PPO policy gradient

更新。

即：

maximize：

J(θ)

因此：

attention只是policy结构，
不是替代RL。


========================================================
13. Reward Design
========================================================

推荐reward：

--------------------------------------------------------
Option A（推荐）
--------------------------------------------------------

r_t =
(phi_{t+1} - phi_t)
/
(|phi_t| + ε)

学习：

dual improvement


--------------------------------------------------------
Option B
--------------------------------------------------------

terminal reward：

r_terminal =
final_dual_bound

学习长期bundle效果。


========================================================
14. PPO Rollout
========================================================

每个episode：

--------------------------------------------------------
Step 1
--------------------------------------------------------

当前bundle：

B_t =
{
    cuts,
    pi_t
}

--------------------------------------------------------
Step 2
--------------------------------------------------------

Policy生成：

1. lambda weights
2. eta

--------------------------------------------------------
Step 3
--------------------------------------------------------

计算：

d_t =
Σ λ_i g_i

--------------------------------------------------------
Step 4
--------------------------------------------------------

更新：

pi_{t+1} =
pi_t + eta_t d_t

--------------------------------------------------------
Step 5
--------------------------------------------------------

solve subproblem：

(g_new, phi_new)

--------------------------------------------------------
Step 6
--------------------------------------------------------

新cut加入bundle：

B_{t+1} =
B_t ∪ cut_new

--------------------------------------------------------
Step 7
--------------------------------------------------------

计算reward：

r_t

--------------------------------------------------------
Step 8
--------------------------------------------------------

PPO更新参数


========================================================
15. 该架构相比当前方案的核心提升
========================================================

当前方案：
--------------------------------
padding + flatten + MLP

问题：
1. 不支持变长
2. 不满足permutation invariant
3. 无法学习cut关系
4. 需要mask


新方案：
--------------------------------
Attention Bundle Policy

优点：
1. 原生支持变长bundle
2. permutation invariant
3. attention天然对应lambda
4. cuts之间可交互
5. 更符合bundle method结构
6. 更适合泛化
7. PPO训练更稳定


========================================================
16. 本质
========================================================

当前研究方向本质是：

RL for Structured Optimization

更具体：

Learning Bundle Aggregation Policy

即：

使用RL学习：
“如何组合历史cuts以更新dual variable”
而不是手工设计bundle heuristic。
