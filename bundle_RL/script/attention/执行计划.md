# Attention Bundle Policy 实现计划

## 一、架构概览

基于 Transformer/Attention 机制学习 Bundle Method 中的 cut 聚合策略和步长策略。

### 1.1 核心设计决策（已确认）

| 模块 | 设计决策 |
|------|---------|
| Observation Space | padding + mask 方式，固定长度 + valid_mask |
| Action Space | [lambda, eta]，两者都是 action |
| Cut 特征 | g_i, phi_i, pi_i（预留 age_i, error_i 字段） |
| 训练框架 | stable_baselines3 PPO |
| Reward | Option A: r_t = (phi_{t+1} - phi_t) / (\|phi_t\| + ε) |
| Critic | 共享 Transformer encoder |
| 更新频率 | 按 step 更新（PPO 原生） |
| Step Size | eta = sigmoid(nn_output)，scale=1 固定 |
| Episode 终止 | 固定步数（t >= max_steps） |

### 1.2 网络结构参数

```
Cut Encoder:
    input_dim = state_dim + 1 + state_dim  # g_i + phi_i + pi_i
    hidden_dim = 64
    output_dim = 64

Transformer:
    d_model = 64
    num_heads = 4
    num_layers = 1-2
    FFN_dim = 128

Global Encoder:
    input_dim = state_dim + trial_point_dim + realization_dim
    hidden_dim = 64
    output_dim = 64

Actor MLP:
    [64, 64] -> output (lambda K 维 + eta 1 维)

Critic MLP:
    [64, 64] -> output (V(s) 1 维)
```

## 三、数据流

```
Observation (dict):
    cuts: (K, state_dim)
    valid_mask: (K,)
    pi: (state_dim,)
    trial_point: (trial_point_dim,)
    realization: (realization_dim,)

    ↓

CutEncoder: 每个 cut 独立编码
    cut_i -> h_i

    ↓

SelfAttention: 聚合 cuts 信息
    [h_1, h_2, ..., h_K] -> [h̃_1, h̃_2, ..., h̃_K]

    ↓

GlobalEncoder: 编码全局信息
    [pi, trial_point, realization] -> g

    ↓ (使用 g 作为 CLS token 或 concat)

LambdaHead: 输出 lambda 分布
    softmax(Linear(h̃_i)) -> λ

    ↓

Direction Aggregation:
    d = Σ λ_i * g_i

    ↓

EtaHead: 输出 eta
    sigmoid(MLP(global_embedding)) -> η

    ↓

Action: [λ, η]

    ↓

Environment Step:
    pi_new = pi + η * d
    solve subproblem -> (g_new, phi_new)
    reward = (phi_new - phi_old) / (|phi_old| + ε)
```
