
# Default Feature 1 架构设计文档

&gt; **模块定位**：在 default_feature 基础上进一步优化，增加新特征并固定步长 eta=0.5。
&gt;
&gt; **设计目标**：新增 search_direction_norm、linear_improvement、cosine_sim 三个特征，简化动作空间（只输出 lambda），保持与 SB3 PPO 标准训练流程兼容。

---

## 一、模块特点

| 维度 | 说明 |
| :--- | :--- |
| 特征提取 | SimpleBundleExtractor（两层 MLP：256 → 128） |
| 特征聚合 | 直接展平拼接所有特征（新增 3 个特征） |
| Policy 类 | MultiInputActorCriticPolicy（SB3 标准） |
| 动作分布 | DiagGaussian（K 维，单分布，不再输出 eta） |
| Env.step | exp(raw_lambda) 归一化，固定 eta=0.5 |
| 新增状态 | search_direction_norm、linear_improvement、cosine_sim |
| 网络复杂度 | 较低，与 default_feature 保持一致 |

---

## 二、整体数据流

```
Observation (Dict)
    │
    ├─ cuts (B, K, state_dim)
    ├─ pi (B, state_dim)
    ├─ trial_point (B, trial_point_dim)
    ├─ realization (B, realization_dim)
    ├─ search_direction_norm (B, 1)
    ├─ linear_improvement (B, 1)
    └─ cosine_sim (B, 1)
    │
    ▼
SimpleBundleExtractor
    │
    ├─ cuts.view(B, K*state_dim)
    ├─ torch.cat([cuts, pi, trial_point, realization, search_direction_norm, linear_improvement, cosine_sim], dim=1)
    ├─ Linear(input_dim → 256) → ReLU
    └─ Linear(256 → features_dim) → ReLU
    │
    ▼
features (B, features_dim)
    │
    ├─ Actor Head: MLP([128, 128]) → Linear(K) → action_mean
    └─ Critic Head: MLP([128, 128]) → Linear(1) → value
    │
    ▼
distribution = DiagGaussian(action_mean, log_std)
action ~ distribution.sample() (B, K)
log_prob, entropy = distribution.log_prob(action), distribution.entropy()
```

环境侧：

```
action = [raw_lambda_1 ... raw_lambda_K]
    │
    └─ raw_lambda: exp → normalize → lambdas (B,K)
    │
    └─ eta = 0.5 (固定步长)
    │
    ▼
d_t  = Σ λᵢ · gᵢ
π_new = π + η · d_t
SubProblem.solve(π_new) → g_new, φ_new
reward = (φ_new - φ_prev) / scale
```

## 三、组件详细规格

### 3.1 SimpleBundleExtractor（特征提取器）

```
cuts (B, K, state_dim) → view(B, K*state_dim)
pi (B, state_dim)
trial_point (B, trial_point_dim)
realization (B, realization_dim)
search_direction_norm (B, 1)
linear_improvement (B, 1)
cosine_sim (B, 1)
    │
    ▼
x = torch.cat([cuts, pi, trial_point, realization, search_direction_norm, linear_improvement, cosine_sim], dim=1)
    │
    ▼
Linear(input_dim → 256)
    │
    ▼
ReLU
    │
    ▼
Linear(256 → features_dim)
    │
    ▼
ReLU → features (B, features_dim)
```

### 3.2 Actor Head（动作头）

```
features (B, features_dim)
    │
    ▼
Linear(features_dim → 128)
    │
    ▼
ReLU
    │
    ▼
Linear(128 → 128)
    │
    ▼
ReLU
    │
    ▼
Linear(128 → K) → action_mean (B, K)
```

### 3.3 Critic Head（价值头）

```
features (B, features_dim)
    │
    ▼
Linear(features_dim → 128)
    │
    ▼
ReLU
    │
    ▼
Linear(128 → 128)
    │
    ▼
ReLU
    │
    ▼
Linear(128 → 1) → value (B, 1)
```

### 3.4 Action Distribution

```
action_mean (B, K)
log_std (learnable nn.Parameter, shape (K,))
dist = DiagGaussian(action_mean, log_std)
action ~ dist.sample() (B, K)
log_prob = dist.log_prob(action) (B,)
entropy = dist.entropy() (B,)
```

直接使用 SB3 标准的 DiagGaussianDistribution。

### 3.5 Env.step（环境步进）

```python
raw_lambda = action[:K]

# Lambda 归一化
exp_lambda = np.exp(raw_lambda)
lambdas = exp_lambda / (np.sum(exp_lambda) + 1e-8)

# 固定步长
eta = 0.5

# 聚合方向
G = state["cuts"]
d_t = lambdas @ G  # (state_dim,)

# 更新 pi
pi = pi + eta * d_t

# 子问题求解
g_new, phi_new = subproblem.solve(pi)

# 计算奖励
reward = (phi_new - phi_prev) / scale
```

### 3.6 新增状态特征计算

```python
# search_direction_norm：上一次 d 的二范数
search_direction_norm = np.linalg.norm(last_d)

# linear_improvement：截距项加权和（截距项 = phi - g · pi）
linear_improvement = 0.0
for i, cut in enumerate(active_cuts):
    intercept = cut["phi"] - np.dot(cut["g"], cut["pi"])
    linear_improvement += last_lambdas[start + i] * intercept

# cosine_sim：最新 g_new 与 d 的余弦相似度
cosine_sim = 0.0
if np.linalg.norm(last_d) &gt; 1e-12 and np.linalg.norm(g_new) &gt; 1e-12:
    cosine_sim = np.dot(g_new, last_d) / (np.linalg.norm(last_d) * np.linalg.norm(g_new))
```

## 五、关键实现要点

1. **新增 3 个特征**：search_direction_norm（上一次 d 的范数）、linear_improvement（截距项加权和）、cosine_sim（最新 g 与 d 的余弦相似度）。
2. **固定步长 eta=0.5**：不再从策略输出 eta，简化动作空间。
3. **简单特征拼接**：将 cuts 展平后与 pi、trial_point、realization 以及 3 个新特征直接拼接。
4. **标准 SB3 Policy**：使用 MultiInputActorCriticPolicy，无需自定义 Policy 类。
5. **两层 MLP 特征提取器**：SimpleBundleExtractor 结构简洁，256 → 128 两层全连接。
6. **独立的 Actor/Critic Head**：各使用 [128, 128] 结构的 MLP，通过 net_arch 配置。
7. **环境 lambda 归一化**：使用 `exp → normalize` 方式。
