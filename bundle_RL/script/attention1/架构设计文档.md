# Attention1 架构设计文档

> **模块定位**：基于 Transformer 编码器 + **自回归 Actor**（Dirichlet λ + Gaussian η）+ **共享 Critic** 的 PPO 策略，用于求解 Bundle Method 中的对偶变量优化问题。
>
> 与 `attention/` 模块的核心差异：
> - **Actor 解耦为两阶段**：先采样 λ（切平面权重），再基于 d_t 条件采样 η（步长），形成自回归结构 π(λ, η | s) = π(λ | s) · π(η | λ, s)
> - **Lambda 头**采用 Dirichlet 分布（Concentration α 由 Query-Key 注意力打分得到），而非 Softmax + 高斯
> - **Eta 头**显式接收 d_t 作为条件输入（detach 切断梯度），消除 λ 与 η 之间的对偶耦合
> - **Critic** 仅依赖 `global_embedding` 与 `h_bundle (CLS)`，**不使用动作信息**，避免 Value Network 依赖 Actor 输出

---

## 一、整体数据流总览

```
Observation
    │
    ▼
┌────────────────────┐
│      Encoder       │  →  cut_embeddings, global_embedding, h_bundle (CLS)
└────────────────────┘
    │
    ├──► Stage 1: Lambda Policy (Dirichlet)        →  λ ~ Dir(α),  log_prob_λ, entropy_λ
    │         │
    │         ▼
    │     d_t = Σ λᵢ gᵢ        (Direction Construction)
    │         │
    ├──► Stage 2: Eta Policy (Gaussian + Sigmoid)  →  η = σ(η_raw),  log_prob_η, entropy_η
    │
    └──► Critic                                    →  V(s)
            │
            ▼
       PPO Loss (action = [λ, η],  log_prob = log_prob_λ + log_prob_η)
            │
            ▼
       Environment Step:  π_new = π + η · d_t  →  SubProblem.solve  →  reward
```

---

## 二、输入：Observation

来自 `BundleDualEnv` 的字典型观测：

| 字段           | 形状                  | 说明                               |
| :------------- | :-------------------- | :--------------------------------- |
| `cuts`         | (B, K, state_dim)     | K 个 cut 的次梯度（含 padding）    |
| `valid_mask`   | (B, K)                | 1 表示有效 cut，0 表示 padding     |
| `pi`           | (B, state_dim)        | 当前对偶变量 π                     |
| `trial_point`  | (B, tp_dim)           | 试验点（来自上层 SDDiP）           |
| `realization`  | (B, real_dim)         | 当前 realization 的场景特征        |

## 三、Encoder：从 Observation 到隐空间表示

### 3.1 CutEncoder

对每个 cut 独立编码：

```
cuts (B, K, state_dim)
    │
    ▼
Linear(state_dim → H) → ReLU → Linear(H → H) → ReLU
    │
    ▼
cut_embeddings_0 (B, K, H)
```

### 3.2 Transformer Encoder × L

引入 **CLS Token**，统一聚合 bundle 全局信息：

```
cut_embeddings_0 (B, K, H)
    │
    │  prepend CLS Token (1, 1, H) → expand to (B, 1, H)
    ▼
sequence (B, K+1, H)
    │
    ▼
TransformerEncoderLayer × L
    ├── Multi-Head Self-Attention (key_padding_mask 来自 valid_mask)
    ├── Add & LayerNorm
    ├── FFN
    └── Add & LayerNorm
    │
    ▼
sequence (B, K+1, H)
    │
    ├──► h_bundle = sequence[:, 0, :]      (B, H)   ← CLS 输出，bundle 整体表示
    └──► cut_embeddings = sequence[:, 1:]  (B, K, H) ← 每个 cut 的精细化表示
```

**关键点**：
- `valid_mask` 拓展为 `[1, valid_mask]` 后构造 `key_padding_mask`，CLS 不被 mask
- 输出 `cut_embeddings` 在无效位置可显式置零（保证下游打分稳定）

### 3.3 GlobalEncoder

编码全局上下文（不参与 attention）：

```
[pi, trial_point, realization]  (B, state_dim + tp_dim + real_dim)
    │
    ▼
Linear → ReLU → Linear → ReLU
    │
    ▼
global_embedding (B, H)
```

### 3.4 Encoder 输出三元组

```
cut_embeddings    (B, K, H)   ── 用于 Lambda 打分
h_bundle (CLS)    (B, H)      ── bundle 整体状态，Actor / Critic 共享
global_embedding  (B, H)      ── 全局上下文，Actor / Critic 共享
```

---

## 四、Stage 1：Lambda Policy（Dirichlet）

**目标**：输出切平面权重 λ ∈ Δ^(K-1)（单纯形上的概率分布）。

### 4.1 Query 构造

```
[global_embedding, h_bundle]  (B, 2H)
    │
    ▼
QueryNet:  Linear(2H → H) → ReLU → Linear(H → H)
    │
    ▼
q (B, H)  →  q.unsqueeze(1) → (B, 1, H)
```

### 4.2 Attention Scores

```
scores = (q · cut_embeddingsᵀ) / √H        (B, 1, K) → squeeze → (B, K)
       │
       │  masked_fill(valid_mask == 0, -inf)
       ▼
scores (B, K)
```

### 4.3 Dirichlet 分布

```
alpha = softplus(scores) + 1e-4    (B, K)
    │
    ▼
Dist = Dirichlet(alpha)
    │
    ├── sample()   →  lambdas (B, K)         ← 落在单纯形上
    ├── log_prob   →  log_prob_lambda (B,)
    └── entropy    →  entropy_lambda (B,)
```

**为何选 Dirichlet**：
- 天然满足 Σ λᵢ = 1 且 λᵢ ≥ 0，免去 Softmax + KL 失配的问题
- α 可解释为"伪计数"，越大表示越尖锐（越接近 one-hot）
- 与 Q-K 打分天然对齐：得分越高 → α 越大 → 该 cut 权重越大

---

## 五、Direction Construction

```
lambdas (B, K)
cuts    (B, K, state_dim)
    │
    ▼
d_t = Σₖ λᵢ · gᵢ         (爱因斯坦求和: einsum("bk, bks -> bs"))
    │
    ▼
d_t (B, state_dim)
```

> **注意**：`d_t` 在传入 Eta Policy 前需 `.detach()`，避免 η 的梯度回流到 λ 的策略网络（解耦两阶段优化）。

---

## 六、Stage 2：Eta Policy（条件高斯 + Sigmoid）

**目标**：在给定方向 d_t 后，输出步长 η ∈ (0, 1)。

```
[global_embedding, h_bundle, d_t.detach()]   (B, 2H + state_dim)
    │
    ▼
EtaNet:  Linear(... → H) → ReLU → Linear(H → 1)
    │
    ▼
mean (B, 1)
    │
    │  log_std (可学习参数, 形状 (1,))
    │  std = exp(log_std)
    ▼
Dist = Normal(mean, std)
    │
    ├── sample()   →  eta_raw (B, 1)
    ├── log_prob   →  log_prob_eta (B,)
    └── entropy    →  entropy_eta (B,)
    │
    ▼
eta = sigmoid(eta_raw)        (B, 1)
```

**关键点**：
- `log_prob_eta` 在 `eta_raw` 上计算（在高斯空间），sigmoid 仅用于环境步进时的范围约束
- 若需在 `eta` 上得到正确密度，需加上 sigmoid 的 Jacobian 修正项；当前实现选择在 raw 空间求 log_prob，避免数值问题
- `log_std` 作为独立参数，与 mean 解耦，便于稳定探索

---

## 七、Critic：Value Network

**仅使用编码器输出，与动作无关**：

```
[global_embedding, h_bundle]  (B, 2H)
    │
    ▼
ValueNet:  Linear(2H → H) → ReLU → Linear(H → H) → ReLU → Linear(H → 1)
    │
    ▼
value V(s)  (B, 1)
```

**为何不输入 λ / d_t / η**：
- Critic 需要估计的是 **状态值** V(s)，而非动作值 Q(s, a)
- 若输入动作，Critic 会变成 Q 函数，与 PPO 优势估计 A = Q - V 的语义混淆
- 保持 Critic 与 Actor 输出解耦，可避免 value bootstrap 时的 leakage

---

## 八、PPO 输出

| 输出量      | 构成                                     | 形状        |
| :---------- | :--------------------------------------- | :---------- |
| `action`    | `[lambdas, eta]`                         | (B, K+1)    |
| `log_prob`  | `log_prob_lambda + log_prob_eta`         | (B,)        |
| `entropy`   | `entropy_lambda + entropy_eta`           | (B,)        |
| `value`     | `V(s)`                                   | (B, 1)      |

> **自回归策略密度**：
> π(λ, η | s) = π(λ | s) · π(η | λ, s)
> ⇒ log π = log π(λ | s) + log π(η | λ, s)（对数空间相加）
> 这与 PPO 的 ratio = exp(log π_new − log π_old) 完全兼容。

---

## 九、Environment Step

环境状态转移与现有 `BundleDualEnv` 一致：

```
action = [lambdas, eta]
    │
    ├── lambdas  → 已是 Dirichlet 采样结果（无需再 softmax）
    └── eta      → 已是 sigmoid 后的 (0, 1) 值
    │
    ▼
d_t = Σ λᵢ · gᵢ
    │
    ▼
π_new = π + η · d_t
    │
    ▼
SubProblem.solve(π_new)
    │
    ├── g_new    (新次梯度)
    └── φ_new    (子问题目标值)
    │
    ▼
reward  =  (φ_new − φ_prev) / scale       (默认实现)
    │
    ▼
append new cut to bundle
    │
    ▼
next observation
```

## 十、关键设计要点总结

### 10.1 Actor：自回归两阶段策略

```
λ ~ Dirichlet(α)            ← 先决定方向上的权重分配
d_t = Σ λᵢ gᵢ               ← 由 λ 与 cuts 共同决定方向
η ~ Normal(mean, std)       ← 在已知方向上决定步长
```

形式化：

> **π(λ, η | s) = π(λ | s) · π(η | λ, s)**

### 10.2 Critic：纯状态值

```
V(s)  ←  仅使用 global_embedding 与 h_bundle
       不使用 λ / d_t / η
```

### 10.3 Encoder：CLS 作为 bundle 表示

```
h_bundle = CLS Token 在 Self-Attention 后的输出
         = bundle 整体状态的紧致表示
         由 Actor 与 Critic 共享
```

### 10.4 与 attention 模块的对比

| 维度          | `attention/`（V1）              | `attention1/`（本设计）                    |
| :------------ | :------------------------------ | :----------------------------------------- |
| Lambda 分布   | Softmax over Gaussian raw       | **Dirichlet(α)** with Q-K 打分              |
| Eta 输入      | global_embedding（独立）        | **[global, CLS, d_t.detach()]**（条件化） |
| Actor 结构    | 同时输出 λ 与 η（独立头）       | **自回归两阶段**                            |
| Critic 输入   | features (pool + global + cls)  | **[global, CLS]**（更简洁，避免 pool 噪声）|
| 单纯形约束    | Softmax 后处理                  | **Dirichlet 天然满足**                      |
| log_prob 维度 | 单一 Normal(K+1)                | **log_prob_λ + log_prob_η**                 |

## 十一、模块组织建议

```
attention1/
├── encoder.py            # CutEncoder + TransformerEncoder + GlobalEncoder（输出 cut_emb / global / h_bundle）
├── policy_network.py     # LambdaHead (Dirichlet) + EtaHead (Conditional Normal) + ValueHead
├── features_extractor.py # 整合 Encoder，对接 SB3 BaseFeaturesExtractor（仅做特征提取，不做策略采样）
├── env.py                # BundleDualEnv（与 attention/ 保持一致或微调）
├── train.py              # PPO 训练流程
├── main_train.py         # 多 config 交错训练入口
└── train_config.yml      # 超参数配置
```

> **实现要点**：
> - 由于 SB3 默认的 `MultiInputActorCriticPolicy` 假设 Actor / Critic 都使用单一分布，而本设计需要 **自回归两分布 + log_prob 相加**，因此应继承 `ActorCriticPolicy` 并重写 `forward / evaluate_actions / predict_values`。
> - Lambda 与 Eta 的采样分别在策略层完成；环境收到的 action 是 **已采样的 λ 与 η**（无需再做 softmax / sigmoid），因此 `BundleDualEnv.step` 中可去掉对应预处理。
