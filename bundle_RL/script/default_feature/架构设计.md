
# Default Feature 架构设计文档

&gt; **模块定位**：简单直接的特征拼接方式，使用标准的 MultiInputActorCriticPolicy，作为基线对比方案。
&gt;
&gt; **设计目标**：将所有输入特征（cuts、pi、trial_point、realization）直接展平拼接，通过简单的 MLP 特征提取器处理，保持与 SB3 PPO 标准训练流程完全兼容。

---

## 一、模块特点

| 维度 | 说明 |
| :--- | :--- |
| 特征提取 | SimpleBundleExtractor（两层 MLP：256 → 128） |
| 特征聚合 | 直接展平拼接所有特征 |
| Policy 类 | MultiInputActorCriticPolicy（SB3 标准） |
| 动作分布 | DiagGaussian（K+1 维，单分布） |
| Env.step | exp(raw_lambda) 归一化，sigmoid(raw_eta) |
| 网络复杂度 | 较低，适合作为基线 |

---

## 二、整体数据流

```
Observation (Dict)
    │
    ├─ cuts (B, K, state_dim)
    ├─ pi (B, state_dim)
    ├─ trial_point (B, trial_point_dim)
    └─ realization (B, realization_dim)
    │
    ▼
SimpleBundleExtractor
    │
    ├─ cuts.view(B, K*state_dim)
    ├─ torch.cat([cuts, pi, trial_point, realization], dim=1)
    ├─ Linear(input_dim → 256) → ReLU
    └─ Linear(256 → features_dim) → ReLU
    │
    ▼
features (B, features_dim)
    │
    ├─ Actor Head: MLP([128, 128]) → Linear(K+1) → action_mean
    └─ Critic Head: MLP([128, 128]) → Linear(1) → value
    │
    ▼
distribution = DiagGaussian(action_mean, log_std)
action ~ distribution.sample() (B, K+1)
log_prob, entropy = distribution.log_prob(action), distribution.entropy()
```

环境侧：

```
action = [raw_lambda_1 ... raw_lambda_K , raw_eta]
    │
    ├─ raw_lambda: exp → normalize → lambdas (B,K)
    └─ raw_eta: sigmoid → eta (B,1)
    │
    ▼
d_t  = Σ λᵢ · gᵢ
π_new = π + η · d_t
SubProblem.solve(π_new) → g_new, φ_new
reward = (φ_new - φ_prev) / scale
```

## 三、组件详细规格

### 3.1 SimpleBundleExtractor（特征提取器）

```
cuts (B, K, state_dim) → view(B, K*state_dim)
pi (B, state_dim)
trial_point (B, trial_point_dim)
realization (B, realization_dim)
    │
    ▼
x = torch.cat([cuts, pi, trial_point, realization], dim=1)
    │
    ▼
Linear(input_dim → 256)
    │
    ▼
ReLU
    │
    ▼
Linear(256 → features_dim)
    │
    ▼
ReLU → features (B, features_dim)
```

### 3.2 Actor Head（动作头）

```
features (B, features_dim)
    │
    ▼
Linear(features_dim → 128)
    │
    ▼
ReLU
    │
    ▼
Linear(128 → 128)
    │
    ▼
ReLU
    │
    ▼
Linear(128 → K+1) → action_mean (B, K+1)
```

### 3.3 Critic Head（价值头）

```
features (B, features_dim)
    │
    ▼
Linear(features_dim → 128)
    │
    ▼
ReLU
    │
    ▼
Linear(128 → 128)
    │
    ▼
ReLU
    │
    ▼
Linear(128 → 1) → value (B, 1)
```

### 3.4 Action Distribution

```
action_mean (B, K+1)
log_std (learnable nn.Parameter, shape (K+1,))
dist = DiagGaussian(action_mean, log_std)
action ~ dist.sample() (B, K+1)
log_prob = dist.log_prob(action) (B,)
entropy = dist.entropy() (B,)
```

直接使用 SB3 标准的 DiagGaussianDistribution。

### 3.5 Env.step（环境步进）

```python
raw_lambda = action[:K]
raw_eta = action[-1]

# Lambda 归一化
exp_lambda = np.exp(raw_lambda)
lambdas = exp_lambda / (np.sum(exp_lambda) + 1e-8)

# 步长映射
eta = 1.0 * (1 / (1 + np.exp(-raw_eta)))

# 聚合方向
G = state["cuts"]
d_t = lambdas @ G  # (state_dim,)

# 更新 pi
pi = pi + eta * d_t

# 子问题求解
g_new, phi_new = subproblem.solve(pi)

# 计算奖励
reward = (phi_new - phi_prev) / scale
```

## 五、关键实现要点

1. **简单特征拼接**：将 cuts 展平后与 pi、trial_point、realization 直接拼接，不做复杂的特征交互。
2. **标准 SB3 Policy**：使用 MultiInputActorCriticPolicy，无需自定义 Policy 类。
3. **两层 MLP 特征提取器**：SimpleBundleExtractor 结构简洁，256 → 128 两层全连接。
4. **独立的 Actor/Critic Head**：各使用 [128, 128] 结构的 MLP，通过 net_arch 配置。
5. **环境 lambda 归一化**：使用 `exp → normalize` 方式，不使用 mask。
