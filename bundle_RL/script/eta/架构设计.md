
# Eta RL 架构设计文档

&gt; **模块定位**：专门用于预测步长 eta 的 RL 模块，同时通过 MasterProblem 求解 lambda 和 pi，保持与原始 bundle 算法兼容性。
&gt;
&gt; **设计目标**：使用新增的 11 维状态特征（包括 log(eta)、log(delta)、serious_step 等），通过简单的 MLP 特征提取器处理，输出 1 维动作来更新 eta。

---

## 一、模块特点

| 维度 | 说明 |
| :--- | :--- |
| 特征提取 | SimpleBundleExtractor（两层 MLP：256 → 128） |
| 特征聚合 | 11 个标量特征直接拼接 |
| Policy 类 | MultiInputActorCriticPolicy（SB3 标准） |
| 动作分布 | DiagGaussian（1 维，单分布） |
| Action Range | [-1, 1]（用于指数更新 eta） |
| 网络复杂度 | 较低，适合作为基准 |

---

## 二、整体数据流

```
Observation (Dict)
    │
    ├─ log_eta (B, 1)
    ├─ log_delta (B, 1)
    ├─ serious_step (B, 1)
    ├─ d_norm_sq (B, 1)
    ├─ proximal_term (B, 1)
    ├─ lin_error (B, 1)
    ├─ gap_improve_1 (B, 1)
    ├─ gap_improve_2 (B, 1)
    ├─ gap_improve_3 (B, 1)
    ├─ g_norm_sq (B, 1)
    └─ cos_gd (B, 1)
    │
    ▼
SimpleBundleExtractor
    │
    ├─ torch.cat([log_eta, log_delta, ..., cos_gd], dim=1)
    ├─ Linear(11 → 256) → ReLU
    └─ Linear(256 → features_dim) → ReLU
    │
    ▼
features (B, features_dim)
    │
    ├─ Actor Head: MLP([128, 128]) → Linear(1) → action_mean
    └─ Critic Head: MLP([128, 128]) → Linear(1) → value
    │
    ▼
distribution = DiagGaussian(action_mean, log_std)
action ~ distribution.sample() (B, 1)  # 范围 [-1, 1]
log_prob, entropy = distribution.log_prob(action), distribution.entropy()
```

环境侧完整流程：

```
1. RL 预测动作 a ∈ [-1, 1]
    │
    ▼
2. 更新 eta: η_new = η_old * exp(0.5 * a)
    │
    ▼
3. 设置 MasterProblem u = 2 * eta，求解 master
    │
    ├─ ub = master objective
    └─ pi_new = master solution
    │
    ▼
4. 计算搜索方向 d = pi_new - pi_old
    │
    ▼
5. 求解 SubProblem(pi_new)，得到 f_new, g_new
    │
    ▼
6. 添加 cut 到 master
    │
    ▼
7. 计算 delta = (ub - f_best) / max(|f_best|, 1)
    │
    ▼
8. 判断 serious_step = (f_new - f_best) &gt;= 0.2 * delta
    │
    ▼
9. 更新状态（f_best, x_best, gap_history）
    │
    ▼
10. 计算 reward = (f_new - f_prev) / scale
```

```

dist = DiagGaussian(action_mean, log_std)

```

直接使用 SB3 标准的 DiagGaussianDistribution。

### 3.5 Env.step（环境步进）

```python
# 1. 接收动作并更新 eta
a = action[0]
eta = eta * exp(0.5 * a)

# 2. 设置并求解 Master
master.u = 2 * eta
ub, pi_new = master.solve()
d = pi_new - pi

# 3. 求解子问题
g_new, f_new = subproblem.solve(pi_new)

# 4. 添加 cut
master.add_cut(pi_new, f_new, g_new)

# 5. 计算 delta
delta = (ub - f_best) / max(|f_best|, 1)

# 6. 判断 serious step
serious_step = (f_new - f_best) &gt;= 0.2 * delta

# 7. 计算 linearization error
lin_error = f_new + g_new · (x_best - pi_new) - f_best

# 8. 更新状态
if serious_step:
    x_best = pi_new
    f_best = f_new

# 9. 计算 reward
reward = (f_new - f_prev) / scale
```

## 四、状态（Observation）详情

### 4.1 Observation Components

| 特征名 | 说明 | 初始值 |
| :--- | :--- | :--- |
| log_eta | log(eta)，eta 初始为 0.5 | log(0.5) ≈ -0.693 |
| log_delta | log(delta)，delta 相对 gap | 0.0 |
| serious_step | 是否为 serious step（0 或 1） | 0.0 |
| d_norm_sq | ||d||²，搜索方向的平方范数 | 0.0 |
| proximal_term | eta * ||d||²，二次项大小 | 0.0 |
| lin_error | Linearization error | 0.0 |
| gap_improve_1 | log(delta_now) - log(delta_prev) | 0.0 |
| gap_improve_2 | log(delta_now) - log(delta_prev2) | 0.0 |
| gap_improve_3 | log(delta_now) - log(delta_prev3) | 0.0 |
| g_norm_sq | ||g_new||²，新梯度的平方范数 | 根据初始解 |
| cos_gd | cos(g_new, d)，新梯度与搜索方向的余弦相似度 | 0.0 |

### 4.2 状态维护

除了上述 observation，env 内部还需维护：

| 内部变量 | 说明 |
| :--- | :--- |
| pi | 当前 dual 变量值 |
| x_best | 最好的 pi（稳定中心） |
| f_best | 最好的下界 |
| i_u | weight update counter |
| gap_history | 历史 delta 记录（用于计算 gap_improve） |
| cuts_storage | 历史 cuts 存储 |
| MasterProblem instance | 完整的 master 问题实例 |
| SubProblem instance | 完整的 sub 问题实例 |

## 六、关键实现要点

1. **11 个标量特征**：所有 observation 都是标量，直接拼接输入 MLP。
2. **eta 更新公式**：eta_new = eta_old * exp(0.5 * a)，确保 eta 为正且变化平滑。
3. **兼容原算法**：使用和原 lag_problem 一致的 MasterProblem 和 SubProblem。
4. **维护完整状态**：f_best, x_best, gap_history, i_u 等状态变量都需维护。
5. **Reward 保持一致**：使用 (f_new - f_prev) / scale，与 default_feature 模块相同。
