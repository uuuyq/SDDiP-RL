# Attention1 架构设计文档（简化版：单一高斯分布，无 eta）

> **模块定位**：在 `attention/` 模块基础上，引入 **CLS Token** 与 **Q-K 注意力打分** 的 Lambda Head，但保持 **单一 DiagGaussian 动作分布**，与 SB3 PPO 标准训练流程完全兼容。eta 已从动作空间移除，固定为 1.0。
>
> **设计目标**：在最小改动 SB3 调用约定的前提下，引入更结构化的 Actor 头（Lambda 用 Q-K 打分，无 Eta），代码风格与 `attention/` 保持一致。

---

## 一、与 attention/ 模块的差异

| 维度          | `attention/`（V1）                     | `attention1/`（简化版，无 eta）                          |
| :------------ | :------------------------------------ | :------------------------------------------------------ |
| Encoder       | CutEnc + SelfAttention + GlobalEnc    | **同上**（共享设计）                                     |
| 特征聚合      | `pool(cut_emb) ⊕ global ⊕ cls`       | **`global ⊕ cls`**（去除噪声较大的 pool）              |
| Lambda 计算   | features → MLP → Linear(action_dim)   | **Q-K Attention：q = QueryNet([global; CLS]) → q · Hᵀ** |
| Eta 计算      | features → MLP → Linear(action_dim)   | **已移除，固定为 1.0**                                  |
| 动作分布      | DiagGaussian（K+1 维，单分布）         | **DiagGaussian（K 维，单分布）**                         |
| Env.step      | softmax(raw_lambda)*mask 后再归一化   | **mask_fill(-inf) → softmax**（更标准）                 |
| Critic 输入   | `pool ⊕ global ⊕ cls`                | **`global ⊕ cls`**                                       |
| Policy 类     | `MultiInputActorCriticPolicy`         | **自定义 `AttentionActorCriticPolicy`**                  |

> 与 `attention1/架构设计文档.md`（自回归 Dirichlet 版）相比：
> - **本简化版** 仍使用单一 Normal 分布，PPO log_prob 在 `[lambda_mean; eta_mean]` 上一次性计算
> - 自回归 Dirichlet 版需要分别采样 λ 与 η 并相加 log_prob，实现更复杂

## 二、整体数据流

```
Observation
    │
    ▼
┌────────────────────┐
│      Encoder       │  →  H = cut_embeddings (B,K,H)
│                    │     CLS = h_bundle (B,H)
│                    │     global_embedding (B,H)
└────────────────────┘
    │
    ├──► LambdaHead:  q = QueryNet([global; CLS]) → scores = q @ Hᵀ / √H  →  lambda_mean (B, K)
    │
    └──► ValueHead:   MLP([global; CLS])  →  value (B, 1)

action_mean = lambda_mean  (B, K)
log_std (learnable nn.Parameter, shape (K,))
distribution = Normal(action_mean, exp(log_std))
action ~ distribution.sample()         (B, K)
log_prob, entropy = distribution.log_prob(action), distribution.entropy()
```

环境侧：

```
action = raw_lambda
    │
    └── raw_lambda ──► masked_fill(valid_mask==0, -inf) ──► softmax ──► lambdas (B,K)
    │
    ▼
d_t  = Σ λᵢ · gᵢ
π_new = π + 1.0 · d_t  # eta 固定为 1.0
SubProblem.solve(π_new) → g_new, φ_new
reward = (φ_new - φ_prev) / scale
```

## 三、组件详细规格

### 3.1 Encoder（与 attention/encoder.py 保持一致）

```
cuts (B, K, state_dim)
    │
    ▼
CutEncoder: Linear → ReLU → Linear → ReLU
    │
    ▼
cut_embeddings_0 (B, K, H)
    │
    │ prepend CLS Token (1,1,H) → expand
    ▼
sequence (B, K+1, H)
    │
    ▼
SelfAttention × num_layers (key_padding_mask 由 valid_mask 拓展构造)
    │
    ▼
sequence (B, K+1, H)
    │
    ├─► h_bundle = sequence[:, 0]     (B, H)   ← CLS
    └─► H        = sequence[:, 1:]    (B, K, H)

[pi, trial_point, realization]
    │
    ▼
GlobalEncoder: Linear → ReLU → Linear → ReLU
    │
    ▼
global_embedding (B, H)
```

输出三元组：`(H, h_bundle, global_embedding)`，后两者拼接得到 `h = [global; CLS]`，shape `(B, 2H)`。

### 3.2 LambdaHead（Q-K Attention 打分）

```python
q = QueryNet(h)                          # (B, 2H) → (B, H)
q = q.unsqueeze(1)                       # (B, 1, H)
scores = (q @ Hᵀ) / sqrt(H)              # (B, 1, K) → squeeze → (B, K)
return scores                            # 作为 lambda_mean
```

QueryNet 结构：`Linear(2H → H) → ReLU → Linear(H → H)`

> **注意**：Actor 中 **不做 mask 与 softmax**，输出 raw scores。mask + softmax 在 `Env.step` 中完成（与 attention/ 一致）。

### 3.3 EtaHead（已移除）

eta 已从动作空间移除，固定为 1.0。

### 3.4 Action Distribution

```python
action_mean = lambda_mean                # (B, K)
std         = exp(log_std)               # (K,) 可学习
dist        = Normal(action_mean, std)
action      = dist.sample()              # (B, K)
log_prob    = dist.log_prob(action).sum(-1)  # (B,)
entropy     = dist.entropy().sum(-1)     # (B,)
```

直接复用 SB3 `DiagGaussianDistribution.proba_distribution(mean, log_std)` 接口。

### 3.5 ValueHead（纯状态值）

```python
value = MLP(h)   # (B, 2H) → (B, 1)
```

结构：`Linear(2H → H) → ReLU → Linear(H → H) → ReLU → Linear(H → 1)`

> Critic 与 Actor 共用编码器（`features_extractor` 共享），但 head 独立。

### 3.6 Env.step（与 attention/env.py 风格一致）

```python
raw_lambda = action[:K]

# Lambda：mask + softmax
masked_logits = raw_lambda.copy()
masked_logits[valid_mask == 0] = -np.inf
exp_l = np.exp(masked_logits - np.max(masked_logits))
lambdas = exp_l / (np.sum(exp_l) + 1e-8)

# Eta：固定为 1.0
eta = 1.0

d_t  = lambdas @ G                        # (state_dim,)
pi   = pi + eta * d_t
g_new, phi_new = subproblem.solve(pi)
reward = (phi_new - phi_prev) / scale
```

## 四、自定义 Policy：AttentionActorCriticPolicy

继承 `stable_baselines3.common.policies.ActorCriticPolicy`，重写：

```
forward(obs, deterministic)
    ├─ encode(obs) → (H, global, cls, valid_mask)
    ├─ h = concat(global, cls)
    ├─ action_mean = [LambdaHead(h, H), EtaHead(h)]
    ├─ dist = action_dist.proba_distribution(action_mean, log_std)
    ├─ action = dist.get_actions(deterministic)
    ├─ log_prob = dist.log_prob(action)
    └─ value = ValueHead(h)
    return action, value, log_prob

evaluate_actions(obs, action)
    ├─ encode(obs) → (H, global, cls, _)
    ├─ h = concat(global, cls)
    ├─ action_mean = [LambdaHead(h, H), EtaHead(h)]
    ├─ dist = action_dist.proba_distribution(action_mean, log_std)
    ├─ log_prob, entropy = dist.log_prob(action), dist.entropy()
    └─ value = ValueHead(h)
    return value, log_prob, entropy

predict_values(obs)
    ├─ encode(obs) → (_, global, cls, _)
    ├─ h = concat(global, cls)
    └─ value = ValueHead(h)

_predict(obs, deterministic)
    （与 forward 中 action 相同）
```

`features_extractor` 仍由父类创建（用于满足 SB3 内部约定），但本 Policy 在 `forward` 中绕过 `mlp_extractor` / `action_net` / `value_net`，全部走自定义 head 路径。

## 七、关键实现要点

1. **DiagGaussian 兼容**：`action_dist` 由父类 `_build_mlp_extractor` 创建，`self.log_std` 也由父类创建为 `nn.Parameter(zeros(K))`。我们仅需调用 `self.action_dist.proba_distribution(mean, self.log_std)`。
2. **避免编码器重复调用**：自定义 `forward` 直接调用 `self.features_extractor.encoder(...)` 拿到三件套，**不调用** `self.features_extractor.forward(obs)`，避免重复前向。
3. **Q-K 打分维度对齐**：`q.unsqueeze(1) @ H.transpose(1,2)` → `(B,1,K)` → `squeeze(1)` → `(B,K)`，缩放因子 `1/√H`。
4. **环境兼容**：环境 `action_space` 是 `Box(low=-10, high=10, shape=(K,))`，只包含 lambda；env 内部完成 mask+softmax，eta 固定为 1.0。
5. **代码风格对齐 attention/**：模块顶部统一注释结构、网络组件分文件、训练函数签名/CSV 日志/checkpoint 续训保持一致。
