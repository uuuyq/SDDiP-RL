# Bundle_RL 模块分析文档

## 概述

`bundle_RL` 模块实现了基于强化学习的 Bundle Method 求解器，用于解决电力系统机组组合（Unit Commitment）问题中的拉格朗日对偶问题。该模块将传统的 Bundle Method 与 PPO（Proximal Policy Optimization）算法结合，通过神经网络学习更优的切平面组合策略。

**设计目标**：使用强化学习加速Bundle算法的迭代过程，让RL根据当前收集的cut推断出下一个π值，从而加速Bundle迭代的收敛。

---

## 问题背景

### 多阶段随机混合整数规划问题

需要解决的问题是**多阶段随机混合整数规划问题**，其特点在于：
- **多阶段**：电力系统中通常以24小时为一个调度周期，分为多个阶段（时间步）
- **随机性**：风电、光伏等可再生能源出力具有不确定性，通过场景采样（Scenario Sampling）处理

在SDDiP算法中，每个阶段和每个随机场景都需要计算一次Lagrangian对偶问题，即需要Bundle迭代。

### Bundle算法迭代过程

Bundle算法迭代分为两个阶段：
1. **主问题求解**：一个二次规划问题（携带近端项），得到π值
2. **子问题求解**：根据主问题的解，计算新的切平面，更新权重，重复直到收敛

### 当前实现现状

当前实现（bundle_RL模块）仅针对**单个阶段的单个场景**进行训练和使用。

## 1. lag_problem.py - 核心Bundle Method实现

### 1.1 SubProblem（子问题类）

**功能**：作为Oracle，为Master提供函数值和子梯度。

**求解目标**：
$$\phi(\pi) = \min_x L(x, \pi)$$

**主要方法**：
- `init_model()`: 初始化Gurobi模型，构建反向模型（backward model），添加电力系统约束（潮流平衡、储能、发电机、爬坡率等）
- `solve(pi)`: 求解子问题，输入对偶变量π，返回子梯度g和最优值φ

### 1.2 MasterProblem（主问题类）

**功能**：管理Bundle Method的主求解过程，维护切平面集合并进行权重更新。

**关键属性**：
- `u`: 权重参数，控制信赖域大小
- `u_min`: 权重下界（0.1）
- `m_l`, `m_r`: Serious Step判定参数（分别为0.2和0.5）
- `x_best`: 稳定中心（当前最优解）
- `f_best`: 下界（稳定中心对应的最优目标值）
- `cuts_storage`: 存储所有切平面

**关键方法**：
- `solve_master()`: 求解主问题，返回预测上界和新的候选点π
- `add_cut(x_new, f_new, g_new)`: 添加新切平面：$v \leq f_{new} + \sum g_{new}(x - x_{new})$
- `update_strategy()`: 权重更新策略，包含Serious Step判定

**算法逻辑**：
```
Master → Sub → add_cut → weight_update
```

## 2. bundle_env.py - 强化学习环境

### 2.1 ProblemData（数据容器）

封装子问题所需的参数，包括logger、problem_params、trial_point、时刻t、场景n和迭代i。

### 2.2 BundleDualEnv（Gymnasium环境）

将Bundle Method包装为强化学习环境。

**状态空间（Observation Space）**：
```python
{
    "cuts": Box(shape=(K, state_dim)),  # 切平面矩阵（padding至K行）
    "pi": Box(shape=(state_dim,))       # 当前对偶变量
}
```

**动作空间（Action Space）**：
```python
Box(shape=(K+1,))  # 前K维是lambda权重，最后1维是步长eta
```

**核心方法**：
- `reset()`: 初始化环境，用π=0求解首次子问题
- `step(action)`: 执行动作，更新π，求解子问题，返回奖励
- `_get_state()`: 获取当前状态，从bundle中提取最后K个切平面

**奖励函数**：
$$reward = \frac{\phi_{new} - \phi_{old}}{scale}$$

## Bundle Network 核心思想

参考论文："Bundle Network: a Machine Learning-Based Bundle Method"

### 问题背景

学习目标：$\min_{\pi \in \Pi} \phi(\pi)$

其中 $\phi(\pi)$ 是凸非光滑函数，$\pi$ 是对偶变量（Lagrangian multipliers）。

目标：学习Bundle Method中的search direction、step size和dual update，避免传统Bundle Method中每步都解QP和手工调节proximal parameter的问题。

### 传统Bundle Method

在历史迭代中收集Bundle：$\beta_t = \{(g_i, \alpha_i)\}_{i=1}^t$

- $g_i \in \partial \phi(\pi_i)$ 是subgradient
- $\alpha_i = \phi(\bar{\pi}) - \phi(\pi_i) - g_i^T(\bar{\pi} - \pi_i)$ 是linearization error

### Proximal Bundle Master Problem

传统Bundle Method求解：
$$\min_d \phi_{\bar{\pi}, \beta_t}(d) + \frac{1}{2\eta}\|d\|^2$$

其中 $d$ 是search direction，$\eta$ 是proximal regularization/step size。

### 对偶Master Problem（核心创新）

不直接解primal QP，而是解其对偶形式：
$$\max_\theta -\frac{\eta_t}{2}\left\|\sum_i g_i \theta_i\right\|^2 + \sum_i \alpha_i \theta_i$$

约束：$\sum_i \theta_i = 1, \theta_i \ge 0$

因此 $\theta \in \Delta_t$，即simplex上的convex combination。

### 聚合梯度（Aggregated Subgradient）

得到：$w_t = \sum_i g_i \theta_i^{(t)}$

它是bundle中所有subgradient的convex combination。

随后：$d_t = \eta_t w_t$

### 下一步对偶变量更新

最终：$\pi_{t+1} = \bar{\pi}_t + \eta_t w_t$

如果要求非负：$\pi_{t+1} = \sigma(\bar{\pi}_t + \eta_t w_t)$，其中 $\sigma$ 是ReLU等nonnegative activation。

### 神经网络预测 (η, θ)

论文核心：用神经网络直接预测 $(\eta_t, \theta_t)$，替代传统Bundle Method中求解Dual Master Problem的过程。

**网络结构**：
- 使用LSTM进行序列编码
- 使用Attention预测 $\theta$：$\delta_i^{(t)} = k_i^T q_t$，然后 $\theta^{(t)} = \psi(\delta^{(t)})$
- Attention本质上在回答"哪些历史subgradient更重要"这个问题

### Bundle Network完整流程

```
Step 1: 收集bundle {(g_i, α_i)}
Step 2: Feature extraction: φ_t = f(β_t)
Step 3: LSTM编码: φ_t → h_t
Step 4: Attention: (q_t, k_t) → δ_t
Step 5: Softmax: δ_t → θ_t
Step 6: 聚合梯度: w_t = Σ g_i θ_i
Step 7: 预测step size: η_t
Step 8: 更新对偶变量: π_{t+1} = π_t + η_t w_t
```

## 多阶段多场景拓展

### SDDiP算法结构分析

参考 `sddipclassical_without_binary.py`，SDDiP算法包含：

1. **Forward Pass（前向过程）**：
   - 对每条样本路径，依次求解各阶段
   - 阶段之间传递trial point（x, y, x_bs, soc）
   - 计算路径上各阶段目标值之和

2. **Backward Pass（后向过程）**：
   - 从最后一个阶段向前遍历
   - 对每个阶段、每个样本、每个场景求解子问题
   - 收集Lagrangian cuts
   - 按概率加权计算cut coefficients

### 当前实现的局限

当前bundle_RL实现仅处理单个阶段单个场景，无法体现：
- 阶段间的依赖关系
- 场景间的统计特性
- cut的跨阶段传递机制

### 拓展方向

**设计想法**：每个阶段训练出一个RL模型，RL模型通过训练泛化到不同的随机场景以及不同的cuts收集，从而可以对同一个阶段的不同问题进行求解。

**关键挑战**：
1. **状态表示**：如何编码历史cut信息（可能跨多个阶段）
2. **场景泛化**：训练时见过的场景与测试时的新场景分布差异
3. **阶段耦合**：各阶段的决策相互影响
4. **计算效率**：每个阶段每个场景都需要Bundle迭代
