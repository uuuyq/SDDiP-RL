## 模块说明

### 根目录文件
| 文件 | 说明 |
|------|------|
| `config.py` | 全局配置参数管理 |
| `main_train.py` | 训练流程入口 |
| `main_test.py` | 单例测试入口 |
| `main_test_all.py` | 全量测试入口 |
| `parallel_train.py` | 并行训练入口 |
| `export_tensorboard.py` | TensorBoard日志导出工具 |

### script 目录
| 子模块 | 说明 |
|--------|------|
| `default` | 默认的强化学习环境和训练实现 |
| `default_feature` | 基于特征的默认实现版本 |
| `mask` | 带掩码策略的强化学习实现 |
| `attention` | 基于Attention机制的强化学习实现 |
| `set` | 集合操作相关模块 |

### 核心文件职责
- **bundle_env.py**: 定义强化学习环境，包含状态、动作空间和奖励机制
- **bundle_env_mask.py**: 带掩码策略的环境实现
- **train.py**: 训练逻辑，包含策略优化、经验回放等
- **utils.py**: 辅助工具函数
- **logger.py**: 训练过程日志记录
- **features.py**: 特征提取与处理
- **lag_problem.py**: 滞后问题处理
- **policy_mask.py**: 掩码策略网络实现

### attention 模块架构
基于Transformer/Attention机制学习Bundle Method中的cut聚合策略和步长策略，核心包括：
- **Cut Encoder**: 对每个cut进行独立编码
- **Self-Attention**: 聚合cuts信息
- **Global State Fusion**: 融合全局状态信息
